# Development storage

Keep active repositories, dependency environments, builds, jobs, databases, locks and bounded caches in a verified local directory outside cloud sync. Never use university OneDrive as a live ChemDraw job store.

Use the owner's authorized private Chembridge folder for selected inputs, full acceptance evidence and inactive archives. Inspect metadata first and retrieve only needed files. Before releasing a cold local copy, download the archive again and verify size and SHA-256. Use Free up space for synced placeholders; deleting a synced file deletes its cloud counterpart. Retain the active runtime and a usable rollback version.

Publish only source, documentation, small synthetic test inputs, sanitized evidence and distributable packages on GitHub. Vendor software, licences, accounts and private academic data remain private. Record machine paths and cloud locations in ignored local receipts.

Deliver results to the user's selected authorized folder or host artifact channel. Native execution, attachment receipt, manual download and automatic saving have separate evidence. OneDrive upload and any particular browser download method are not universal gates. No automatic cleanup or cloud offloading is implemented by this policy.
