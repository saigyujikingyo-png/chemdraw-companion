## Required corrections

### 1. High: native semantic/anchor verification can miss material corruption

[verify_composition.py](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/verify_composition.py#L26) checks hydrogen/valence using IR values instead of comparing the actual native hydrogen representation. A readback fault injection adding NumHydrogens=4 to the selected carbon still returns semantic_and_native_inventory=pass and the same chemical fingerprint.

Its [lone-pair checks](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/verify_composition.py#L49) test object existence/type, and its [curve checks](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/verify_composition.py#L65) primarily compare to pre-import mapping coordinates. In-memory readback controls moved a complete state's atoms/labels by +500 pt while leaving arrows/lone pairs behind, or moved one lone-pair graphic to the page origin; those changes did not fail the semantic/inventory result.

These are comparator fault injections, not new vendor executions. The report already leaves complete mask quality unverified; the issue is that it cannot yet certify the claimed hydrogen/semantic-anchor preservation.

Required: compare native explicit/inferred H with the intended graph; reconstruct ports from actual reopened atoms/bonds/lone-pair geometry and reconcile occurrence mappings; check page containment and permitted anchor deviation. Add negative controls for changed H, displaced fragments, detached pairs/curves and missing object properties. Retain full-mask quality as an independent required check.

### 2. High for qualification: prove the intended native edit, not merely equality after reopening

[verify_native_edits.py:14](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/verify_native_edits.py#L14) compares post-edit with reopened snapshots without proving the requested change against the before snapshot. A negative control replaced post-edit and reopened curves/symbols/captions with their before values: both formats still passed. The actual checkpoint events do contain edits (11 atoms, one curve, three symbols and one caption changed in each format); the defect is a false-pass path in future qualification.

The [snapshot](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/native-edit-proof.ps1#L9) omits bonds and several chemical/object-type fields, so equality cannot prove that only declared changes occurred.

Required: record immutable operation intent and before/after/reopen snapshots; assert the exact intended nonzero diff; compare the full scene with only declared changes whitelisted. Include no-op setter, wrong-object edit, bond/charge/H/stereo loss, arrowhead loss and warning controls. Do not describe current actual edits as absent.

The [CLI](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/verify_native_edits.py#L34) also exits normally when its JSON reports failed. Required automated gates must return nonzero on failure while preserving the report; process exit alone still cannot establish scientific acceptance.

### 3. Native provenance must bind the geometry to an executed native receipt

[read_geometry](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/runtime/adapters/chemdraw_cdxml.py#L101) unconditionally labels accepted geometry as ChemDraw native Clean(true) readback; the [compose entry](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/probes/run_composer.py#L16) does not bind it to an executed native receipt. Supplying either archived pre-native seed folder was accepted for all seven states and received that native source label.

This demonstrates an incorrect-provenance path, not absence of actual native execution in the delivered checkpoint. Require a matching executed operation receipt and input/output/style/build hashes before making a native-generation/cleanup claim; otherwise retain an unverified or non-native-input stage. Never let a filename, caller-supplied directory or parser success certify its producer.

### 4. Known failure independently confirmed: input-order ties affect Composer output

No explicit Beckmann/state-number/7-6-15 template dispatch was found in the reviewed generic runtime. However, [connected_components](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/runtime/chemical_ir.py#L21) starts from catalog order; [component sorting and packing](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/2cc659771817f9968b8ed09b40b2335e32b0fdc7/runtime/mechanism_composer.py#L49) leave equal signatures/costs tied by enumeration. Reordering only atom_catalog, without renaming IDs or changing chemistry/geometry, reproduces the reported maximum displacement of 84.3 pt. Equal-priority flow routing also retains order-dependent choices.

The 84.3 pt number is a measured behavior difference, not a universal chemical-quality threshold. Distinguish harmful dependence on opaque input ordering from explicitly permitted symmetries of truly indistinguishable components. Use mechanism-wide chemical/transition context and general geometric tie rules; do not replace the dependence with numeric ID sorting or sample-specific positions. Re-run relabeling, array permutation, simultaneous-flow reordering, geometry perturbation and supported variable-length controls, comparing relationships and quality under the declared equivalence.
