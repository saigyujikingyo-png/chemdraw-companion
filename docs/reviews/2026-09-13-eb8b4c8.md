The departure's visible tip enters the Br label box. The unrelated caption clearance requires 2.592 pt; the related target still requires a positive visible gap.

The five controlled ablations preserve the same molecular input fingerprint. This supports an interaction in this reproducer, not a definitive vendor-internal explanation. The latest complete batch has neutral product O and the expected H/Br charges.

Repair 2 failed Composer preflight before native M1. Both allowed automatic repairs are consumed and remain failed history. The later general gap correction at runtime/annotation_layout.py:14-17 changes the current 14.4 pt bond / 4.22 pt head example from 9.26 to 10.076 pt separation; algebra alone is not native qualification. No third repair may be retroactively inserted into this completed run.

Continue focused shared geometry/adapter work in a newly declared bounded development experiment with a new build and retained lineage. Measure visible native head reach, preserve the semantic donor/acceptor ports, and account for all annotation obstacles. Re-run S1 -> R1 -> M1 and preserve first output and both native formats. ### 2. P2: scene comparison can accept incomplete geometry

[probes/scene_equivalence.py:27-40](https://github.com/saigyujikingyo-png/chemdraw-companion/blob/eb8b4c869a23237f726f8cf127be18743f573a14/probes/scene_equivalence.py#L27) checks coordinates with zip without validating complete inventories and sequence lengths. Independent in-memory controls all return strict pass with zero reported displacement:

- Remove the final point from the first four-point Bezier.
- Add an orphan connector.
- Change the first scene bond order to 3.
- Change the first scene atom charge to 5.

The first two directly contradict complete curve/connector comparison. The latter two show that relationships_equal is not a scene chemistry check; independent native chemical validation may detect them elsewhere. None establishes that the delivered scenes actually contain those faults.

Validate state/object identity sets, duplicates, control/path lengths and full inventories before comparing all points. Validate scene chemical attributes against the IR or bind the comparator to a mandatory independently successful semantic check. Missing/malformed data must fail closed. Keep verified global symmetry handling; do not replace it with ID-specific exceptions.

A correct supplied IR does not prove anti-migration selection. The reference 7 / 6 / 15 counts never become runtime requirements.
